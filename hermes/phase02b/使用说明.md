# 独立数采Hermes：本轮如何使用

本轮交付两个独立启动文件，放在专用“日常入口”文件夹，不替换原Hermes的快捷方式。

1. 双击 **自检数采身份.cmd**，确认显示“Phase02B隔离模拟”、独立数据根检查通过、没有旧任务、只允许demo_browser。
2. **启动数采Hermes.cmd** 打开现有Hermes的独立对话窗口。本轮仅支持本机虚拟演示页，不能访问真实灵生后台。窗口会显示可测试的本机演示地址。
3. 在有效的本轮模型授权期间，可直接用中文让Hermes检查该地址、说明读到了什么和没读到什么。
4. 输入 **/exit** 或关闭独立窗口。只清理本入口的子进程，原Hermes保留原来的入口与设置。

**授权结束后的预期行为**：本轮临时模型凭据会撤下，启动文件仍保留，自检可用；聊天启动会提示当前没有模型授权，不会偷偷使用原身份的凭据。这不是“长期聊天已开通”。长期模型授权/安全保存方式须由Owner另行决定。

该入口当前采用已有Hermes的classic CLI，避免修改原桌面或增加前端依赖。尚未把独立身份接入原Desktop图形界面，也未完成在Windows原生窗口双击后的人工视觉验收；启动路径、自检、原生CLI对话和进程退出另有本机测试记录。

下一步先看Gate A报告和PR。之后由你亲自登录灵生、明确允许只读的页面范围，再逐页带Hermes认识菜单、字段、流程及你的工作习惯。这个模拟入口不会自动升级为真实后台权限，也不会开启正式巡检或派单。
