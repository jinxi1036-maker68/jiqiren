# Hermes × Ego：灵生任务表单稳定工具

这是原正式 Hermes 的浏览器动作增强，不是第二名员工，也不替 Hermes 决定工作内容。

2026-11-23 取证发现，一次真实任务创建会话持续约 16 分钟，包含 15 次模型请求、154 次工具调用。Hermes 在多个 TaskSpace 间反复重试，混用 React 值注入、DOM 点击、CDP 坐标点击及长等待，最终把项目/设备空值误归因为“Ego 不稳定”。同日零写入实测证明 Ego 在线，高层语义点击可选中项目和设备并正确读回。

本工具将浏览器机械动作收敛为：单一空间、语义操作、选后读回、提交前全字段核验、最多提交一次、结果不明时禁止重提。业务目标、SOP、设备选择和授权判断仍由 Hermes 自主完成。

- `ldp-task-form.mjs`：生产工具源文件。
- `test-ldp-task-form.mjs`：纯本地请求校验测试，不连接浏览器或模型。
- `SKILL_OVERRIDE.md`：部署到本机技能顶部的当前覆盖规则。

安全边界：不包含凭据、Cookie、员工名单、设备号或真实SOP；dry-run 只填表、读回并关闭弹窗；真实提交需同时设置 `submit=true` 和 `writeAuthorized=true`；结果未知时不自动重提。
