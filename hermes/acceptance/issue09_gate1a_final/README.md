# 已发生会话的只读证据核对

本目录提供本轮实际执行的离线证据投影源码，不运行Hermes、模型、MCP或浏览器。原始会话/进程命令行只存本机ACL私有目录；GitHub仅保留指定目标会话的哈希、公司文件读取回执、合成页面及问题清单。

`build_evidence.py`消费本机私有定点只读收集结果，交叉匹配Desktop MCP结果与固定run trace，并导出白名单。私有输入不在仓库，不能在GitHub环境直接重建原始证据。附带的`validate_publication.py`只检查公开交付语法、结构、源内容一致性和脱敏模式，不重做能力测试。

核对范围、证据分层和限制见[报告](../../reports/ISSUE_09_GATE_1A_FINAL_EVIDENCE_REVIEW_2026-10-17.md)。没有任何重跑Agent或清理原环境的入口。本轮曾对相邻普通会话作定位读入；其正文及非验收任务不发布、不用于判断本次能力。
