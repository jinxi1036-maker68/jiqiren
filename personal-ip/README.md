## 使用方式
用户讲真实经历 → 先查索引去重 → 选一个事实驱动的观点与受众 → 写可自然口播的完整稿、钩子、标题、场景补镜建议 → 用户确认 → 归档全文与版本 → 用户实际录制/发布 → 只有取得平台数据后再复盘并调整下次选题。
**写稿不等于已发布；起草的建议不等于用户确认；文案性能未经实际发布无法证明。**
