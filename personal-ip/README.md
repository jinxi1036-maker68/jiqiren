## 核心定位
由经营者本人真人出镜，以普通创业者真实进入具身智能数据采集领域的经历，记录判断、实践、走弯路和修正，逐步建立行业信任，同时吸引拥有工厂、仓库、超市、门店等真实场景的经营者自然交流。**不是企业广告号、培训卖课号，也不包装为行业导师或单向教同行开公司的副业拆解号。**

## 使用方式
用户讲真实经历或确认选题 → 先查索引去重 → 锚定一个有现场颗粒度的真实切口与双受众价值 → **默认只交付精炼完整的口播正文**（拍摄由本人负责，不自动附加镜头/补镜指导，也不强制堆砌多套钩子） → 用户确认 → 归档全文与版本 → 用户实际录制/发布 → 取得真实平台数据后再复盘并调整后续选题。
**写稿不等于已发布；起草的建议不等于用户确认；文案性能未经实际发布无法证明。**

## GitHub隐私底线
仅保留脱敏、适合仓库保存的稿件、非敏感聚合统计、公开链接和决策。不存后台登录信息、私人手机号/微信号、身份证、员工和顾客隐私、客户原始订单及未经授权的采集录像。若用户提供高度敏感事实，写公开文案前先脱敏；不擅自发布。
