# 创始人个人IP｜新会话/新Agent快速接手入口

**归属**：机器人数据采集总项目的 personal-ip 子目录。必须同时尊重总知识库的事实与历史、保密要求。
**状态**：2026-11-17 OWNER_CONFIRMED_DIRECTION；文案写法仍待实际发布检验。

## 必读顺序
1. 本文及 [项目现况](PROJECT_STATE.json)；
2. 创作或策划时读 [定位与口播方法](POSITIONING_AND_PLAYBOOK.md)；
3. **每次写新稿前必须查** [文案索引](../scripts/INDEX.csv)，必要时打开相似稿全文核对故事、观点、开头和目标受众；
4. 写完的稿按 [模板](../scripts/TEMPLATE.md) 保存到 scripts/YYYY/MM/，并更新索引状态；
5. 取得真实发布数据后读 [数据台账](../reviews/OPERATIONS_LOG.csv) 与 [复盘规则](../reviews/REVIEW_METHOD.md)；
6. 新决定与改变进 [发展历史](../history/EVOLUTION.md) 及 decisions/，重大公司进展交叉链接总项目时间轴。

## Owner已经明确确认
- 做**本人真人出镜的个人IP**，不先做公司广告号。
- 讲本人从接触具身智能数据采集到实际经营、持续思考和探索的真实经历。
- 每天可通过聊天/语音提供经历，由助手长期帮助选择内容、设计开头钩子、写自然口播、标题与结尾、拍摄建议、后续复盘。
- 已确认的实际文案与发布反馈需有条目与版本，并检查是否与历史故事重复；知识库积累优点与缺点，不仅留结论也留演变。
- 助手要给实用建议，但建议不自动升级成永久创作规则。

## 还不能宣称已经发生
- 账号开通、具体用户名、某条视频实际发布、获得粉丝/播放/咨询/合作等。
- 抖音优先、视频号同步、小红书适配是初期**讨论建议**，不是已完成的平台运营计划。
- 用户最早使用GPT的完整历史尚未得到完整回放；不能根据局部仓库记录编造个人传记。

## 必须区分状态
IDEA（素材）/ DRAFT（草稿）/ OWNER_APPROVED（用户确认）/ RECORDED（录制）/ PUBLISHED（发布）/ REVIEWED（复盘）/ ARCHIVED（归档）。
在新窗口中，如 GitHub 不可访问或不能写，必须明确说“未同步”；不得暗示后台会自动保存所有未来聊天。
