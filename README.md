## 设计原则
- 聊天不是权威；知识库记录经过确认的当前事实。
- Current 只保存“现在正在做什么”，历史单独归档。
- 已确认事实、待确认信息、经营假设必须分开。
- 新会话只加载当前任务真正需要的上下文，不整库硬读。
- 重要扩张必须由真实试采、真实验收、真实结算证据驱动。

> 本仓库是经营知识库，不存放身份证、手机号、私人微信、银行账户等个人敏感信息。
