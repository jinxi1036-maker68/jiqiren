# 凌矩共享采集站 V0.1

原生微信小程序模拟体验。包含商家端、个人采集员端和单独的凌矩模拟运营工作台。三处示例站点分别演示文具分拣、周转盒装配、仿真花束整理。任务、图片、凭证、设备码和金额均为虚构。

## 用微信开发者工具打开

1. 检出 Draft PR 分支 `codex/wechat-mock-v0.1`。打开微信开发者工具，选择「小程序 → 导入项目」，项目目录选 **`miniapp/apps/wechat/`**。这个目录内有 `project.config.json`。
2. 登录有权限的开发者微信，导入时填自己的小程序 AppID，后端服务选「不使用云服务」。仓库的 `touristappid` 是占位值。本机已用有权限的 AppID 完成桌面模拟器编译与操作验证。模拟器通过后可点「预览」并扫码。若工具写入 `project.config.json`，请把 AppID 变更留在本机。AppSecret 和上传密钥无需提供。
3. 点击「编译」。首次从「我是商家」或「我是采集员」进入，后续普通冷启动会恢复上次身份。点微信的小房子返回首页，或点商家端、采集员端顶部的「切换身份」，会停在双身份选择页。切回采集员后可继续原预约和任务筛选。
4. 打开「编译模式」下拉菜单，选「凌矩模拟运营」。若工具没有自动列出，手动添加自定义编译模式，启动页面填 `pages/ops/index`，启动参数填 `mode=mock-ops`。从运营页打开商家端或采集员端后，可用模拟器左上角返回运营页。也可用「用户入口」编译模式回到双入口。
5. 选择页底部的「重置演示数据」会清除本机模拟订单、身份、时钟、收益和审计。桌面模拟器与手机各自保存本机数据。

本地编译和扫码预览均在开发者工具内进行。工具的安装入口见 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

## 三个演示剧本

每个剧本开始前可先重置。体验版按设备的当前北京时间起算，只能预约尚未开始的时段。当天可约时段不足时，用日期选择器切到未来一天。主动推进时钟或用订单里的快进演示后，首页和预约页会标出「演示快进」。

### 1. 商家从申请到开放和临时暂停

1. 「我是商家」进入「我的演示门店」，点「开始申请」。保留预填的虚构资料，点选门头、室内、设备位置三个照片占位，提交入驻申请。
2. 切到「凌矩模拟运营」编译模式，在「场地」对申请点「模拟通过」，输入模拟审核依据，然后点「登记设备安装」。
3. 由运营页打开商家端，点「确认模拟设备到位」。在「开放时段 → 每周计划」选择用于体验的星期，点「添加一段」，分别选开始与结束。添加 09:00–12:00 和 14:00–18:00 两段，预览后确认变更。
4. 去采集员端，选择对应日期，在新门店预约尚未开始的两小时档。回到同一商家的「工作台」，查看设备状态，并在排班中选择预约日期。点「调整开放时间 → 暂停这一天」，检查受影响预约再确认。采集员在「消息」看到变更，在订单中选「无责取消」或换到其他站点改约。
5. 回到商家「开放时段 → 单日调整」，选同一天，点「恢复周计划」，预览并确认。尚可履行的原预约从受影响恢复，周计划继续保留。

### 2. 预约、采集、归还与分账

每次新预约或改约至少连续 2 小时。选定开始时间后，页面显示最早可选的结束时间。任务上限和当前空档允许时，可以选更长时段。

手机预览可直接点预约页的「今天」「明天」「后天」，或用「更多日期」。当天无空档时，底部会显示最近可约日期，或提供「查看其他日期」。点开始时间后会显示结束档，点「更改」可重新选开始。

从「我是采集员」进入「首页」。顶部搜索支持门店、地址和任务，筛选栏可选择日期、区域、排序及「仅看可约」。站内动态在任务列表后方，每 5 秒切换，也可手动横滑。有预约时，搜索下方显示「下一单」。在「我的」点订单状态或「全部订单」，会在订单卡下展开。

1. 采集员 A 搜索「样例街 A-01」进入松墨文具，查看到店指引并复制地址。选一个未来开始时间，再选最早结束档，核对底栏日期、站点和时段后确认。在「我的 → 演示设置」切到采集员 B，查看同一设备该日剩余的可约时段。切回 A，打开原订单查看设备箱位置和采集区域。
2. 在手机微信预览中，点订单顶部「地图导航」，打开微信内置地图，再从地图界面选择路线。任务页和订单求助区也有入口。地图展示平顶山的示例坐标，虚构站点地址仅用于流程体验。
3. 首页「下一单」可返回本单。预约后先看地图和到店时间，签到后看设备箱位置与模拟密码，开工后看本单 SOP，停采后看如何放回原箱并上锁。底部固定当前可执行的操作。图解可收起，「本单资料」可展开地址等信息，顶部可打开订单求助。需要推进演示时间时，当前步骤会显示推进到的时间。订单结果分列设备「已提交 · 待核验」、质检「待审核」及采集报酬「质检后确认」。
4. 商家端切到「松墨文具（虚构） → 场地收益」，归还待核验单独列出。运营「设备订单」点「模拟核验归还」，输入 `模拟在箱且设备可用`。商家收益增加一笔待结算，金额待定。运营可对该笔点「模拟核账」使用示例 ¥20，再点「标记模拟到账」。商家可以按月份和状态查这笔单及模拟到账时间。
5. 运营「审核」点「录入模拟QA」，输入 `45 / 末段遮挡，请调整视角`。A 的订单显示有效 45 分钟、38%，当月确认虚构报酬 ¥22.50。A 可提出复核，运营输入 `5 / 模拟复查新增5分钟`，原收入保留，补充账目计入下一期。

### 3. 故障白跑、无责取消与补贴申诉

1. 选择同一天能容纳两笔预约的日期。A 先预约松墨文具的两小时档，再为 B 预约同设备至少晚于前一单结束 30 分钟的时段。切回 A，点「模拟开始前往」，通过「遇到问题」选择「设备故障」，提交模拟说明及照片占位。
2. 从运营「今日待办」进入该求助。确认故障时点「核实故障并暂停」，输入模拟故障依据。A 和 B 在站内收到通知。A 在订单无责取消，再「提交模拟凭证并申请」，选择模拟行程凭证。B 可无责取消或改约，未出发时无补贴申请入口。
3. 运营「审核 → 交通补贴」拒绝 A 的模拟申请并填写理由。A 在原订单补充凭证并申诉。运营复核通过后，在 A 的「我的 → 余额」展开明细可看到 **待发放补贴**。用「时钟审计」可查看核查记录，设备修复后用「模拟核验可用并复开」。

## 验证

[验收结果及离线编译截图](evidence/README.md)

### 个人中心与活动体验

1. 采集员点「我的 → 点击登录 → 一键演示登录」。点钱包的「优惠券 → 去领券」领取新人体验券，返回后可在同一张钱包卡内查看。
2. 用采集员 A 打开「邀请好友」，复制演示邀请码。从「我的 → 演示设置」切换到 B，登录后在首次预约前填写。B 完成采集、归还核验和有效质检后，切回 A 查看并记录演示奖励。邀请数据和奖励记录保存在同一台体验设备。
3. 采集员从「我的 → 投诉建议」，已入驻商家从「门店 → 联系凌矩 · 投诉建议」提交一条示例反馈。在凌矩模拟运营的「今日待办」回复，再回原账号查结果。
4. 商家从「门店」查看入驻进度、设备记录、到店指引和商家服务指南。采集员「设置」可关闭首页活动推荐或退出演示登录。

### 门店与模拟扫码

1. 底栏「门店」点一间合作门店，在列表内展开地址、今日开放时间、入口及地图示例点。「我的 → 推荐门店」可提交一条模拟门店推荐。
2. 预约后点底栏中间「扫一扫」。选择该预约门店的模拟设备，点「模拟扫设备码 → 查看订单」，继续本单的前往、签到、取机或归还流程。切到没有该订单的演示采集员后，再扫同一设备会提示未找到匹配订单。
3. 「我的 → 门店积分」展示积分位置及说明。门店发放和核销规则待确认。

真实登录、现金返现及优惠券使用规则待确认。模拟券和邀请奖励均为体验记录。

也可在上述剧本中验证两条异常路径。

- 暂停门店后，受影响订单可从底部「选择其他时段」，也可点「订单求助」，直接填写说明并提交。运营可用「回复并结案」，采集员可在原订单及站内消息看到回复。
- 前一单未核验归还时，后续订单说明等待原因。前单核验完成后，点后续订单底部「刷新订单状态」即可继续。提交求助不会阻止后续的出发或签到。
- 结束采集后，展开订单底部「演示控制」并打开「模拟首次上传失败」，再提交归还。核对归还状态与上传状态分别显示，点击「重试模拟上传」后才进入质检。

从仓库根目录运行以下命令，Node.js 版本建议 20 或以上。

```powershell
$env:LINGJU_COMPILER = Join-Path $lingjuQa 'node_modules/miniprogram-compiler'
node miniapp/apps/wechat/tests/compile.cjs
```

## 体验边界

- 预约提交串行读取本机最新状态并校验、写入一次。两位采集员是同一设备内的演示身份，跨手机并发和同步需要未来的服务端。
- 开放时间按北京时区和同日半小时预约档位计算。读取本机记录时，演示时钟至少更新到设备的当前时间。页面前台每分钟刷新可约时段，提交时重新校验。本机提醒和逾期告警随时钟推进，微信订阅授权和推送待接入。
- 运营入口通过编译参数隔离，仅适用于调试。真实角色鉴权、视频上传、设备可信归还、上游 QA、支付和正式结算均待后续接入。
- 个人小时单价、固定补贴和时长参数为演示值。场地账目核验后先记待结算笔数，金额待定。示例金额和模拟到账只由凌矩模拟运营显式推进，实际费率与打款日期待正式协议确定。
- 首版任务取自三个模拟 SOP 模板。运营可暂停或开放任务新预约，场地照片和出行证据使用预设占位。
