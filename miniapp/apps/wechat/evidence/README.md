- 微信开发者工具 2.02.2609250 的游客模式读到了工程名和配置。在导入表单校验占位 AppID 时返回「系统错误，错误码 1」。账号持有人配置本地 AppID 后，重启工具并编译成功。基础库 3.18.0 下，实际打开双入口首页、采集员任务列表和文具任务详情，看到图文 SOP 与预约控件。修正任务页空值警告后复测，调试器错误计数为 0。真机扫码预览待验收。
