## 此目录就是小程序唯一持续迭代源

- `knowledge/`：产品原则、需求编号、当前状态、技术决定、发展史、开放问题；不要靠旧聊天复原规格。
- `apps/demo/`：Codex以后提交的可点击演示版代码；**当前仅占位，没有正式可执行应用**。
- `apps/wechat/`：以后若决定制作正式微信小程序，其源码放在此；**当前无正式开发授权**。
- `tests/`：后续单元/界面/流程测试及测试说明；`releases/`存每次版本说明和验收证据。
- `CHANGELOG.md`：按版本记录实际合并/交付的变更；不是讨论流水。
- `AGENTS.md`：Codex和其他编程Agent必须遵守的交接规则。

**与公司主知识库关系：**`knowledge/00_START_HERE.md`（仓库原有主入口）负责公司全局；`miniapp/knowledge/00_START_HERE.md`负责本项目。重要产品演变同时在公司发展时间轴留一条索引。**不新建第二套并行权威仓库，也不把小程序代码塞进公司的业务台账目录。**
