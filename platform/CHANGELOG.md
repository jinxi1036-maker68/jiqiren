# `platform/` 变更记录

## v2.0.0（2026-11-26）｜整包项目制 ＋ 小优上游数据回流隔离墙 ＋ AI 异常升级工单台
- **业务底座重塑（整包项目制）**：`task_packs` 全面升级为 `projects`（支持 1,000h–10,000h 总量配额池、多代理切片分配与进度条追踪、上游平台隔离模式 `受限传片子账号` vs `全屏蔽中转`、以及 `project_rule_revisions` 动态规则变更提炼广播与代理强制已读回执）。
- **小优上游 QA 抓取回流隔离墙（`xiaoyou_qa_reports`）**：彻底切断代理直看甲方平台路径；审批锁单时强制绑定 `设备号清单 / 上传子账号` 作为归因钥匙；总控可一键导入/同步上游报表自动匹配代理、将生涩 Bad 编码翻译为大白话拍照整改建议并算出 `QA 预估净收益（未决算）` 隔离回显给代理，经总控 10 秒核对后无缝转入背靠背实结台账。
- **专属项目小优一线 ＋ 人工异常升级（`agent_ai_messages` ＋ `escalation_tickets`）**：逻辑上每对 `(项目 × 代理)` 隔离上下文答疑，触发改价、QA 申诉、损赔或连续异常自动创建升级工单推给总控人工督导解决。
- **上线刚需小工具全补齐**：新增飞书 Webhook 群通知（支持环境变量配置）、用户自主改密与总控一键重置代理密码、以及财务三方台账一键导出 UTF-8 BOM CSV。

## v1.2.0（2026-11-26）｜专业级 SaaS 视觉系统与经营总览控制台升级
- **直面痛点重塑专业度**：彻底移除所有系统 Unicode Emoji 图标与表内 `【演示】` 开发调试后缀，全面采用 1.8px 矢量 SVG 线性图标体系、`tabular-nums` 等宽财务数字对齐与圆点状态胶囊（Status Pill）。
- **总览首页告别大面积空洞与全 0 空壳**：总控台新增 `5 节点 S2B 协同交付漏斗`、`待您拍板事项队列`（支持直接点击按钮呼出对应审核/对账抽屉）、`已确认批次三方分账实时核算`与`平台风控硬锁状态面板`；代理工作台首页升级为可视化三步执行进度条与准入条款栏。
- **三层企业工作台与分屏门户**：左侧 Obsidian 深空导航栏 + 顶部面包屑与风控状态条（Topbar） + 右侧全宽流式工作区；登录页重做为 50/50 分屏价值展示页，公开老板场景登记页加入三项脱敏/合规/零费用信任背书卡与编号表单步骤。
- **补全演示流水线闭环 (`src/seed.js`)**：在完全兼容 `tests/api.test.js` 的前提下，预置 1 条待初筛场景、1 条待点绿灯首件样本及 1 条绿灯运行中派单与 2 条对账批次。

## v1.1.0（2026-11-26）｜前端信息架构全面重构（左侧大模块导航 ＋ 右侧二级工作区 ＋ 滑出抽屉）
- 响应 Owner 实测体验反馈（原版文字过密、主次不清、缺少左侧主导航与二级分层），全面重做 `public/` 前端布局：
  1. **左侧固定一级大模块导航 ＋ 实时红点待办计数**（总控台分：总览首页 / 资源中心 / 派单与首件 / QA与对账 / 认证代理库；代理端分：工作台首页 / 资源承接大厅 / 我的交付执行 / 我的背靠背账单）；
  2. **右侧顶部二级小模块 Tab 切换**，列表全宽舒展展示，彻底消除左右硬挤与视觉拥挤；
  3. **所有新建、分级审批、QA回填与日报提交表单统一收进右侧滑出抽屉（Drawer）**，常规浏览界面信息密度大幅下降；
  4. **100% 纯中文状态字典**，全面替换原界面暴露的英文状态码（如 `PAID`、`enterprise_vat`、`S2_RESERVE`）。

## v1.0.0（2026-11-26）｜极简真可用 1.0 Web 平台首版落地
- 基于 Owner 确认的 6 大模块规范及终局第一性原理深清查报告，正式开辟 `platform/` 源码专区。
- 实现零第三方依赖 Node.js + SQLite（WAL 模式）后端：含 `scrypt` 加盐密码与 `HttpOnly` 签名会话、严格 RBAC 角色隔离与 DTO 脱敏裁剪、后台发号认证代理库、合规路径锁任务池、`S1/S2` 双层全国场景池、公开 30 秒零承诺留资页、系统级 `1–2h` 首件试采熔断绿灯引擎、以及背靠背三方对账台。
- 交付总控台、认证代理工作台与实体老板备案页三端一体化响应式界面。
- 配套阿里云 Linux systemd 低内存服务模板（`MemoryMax=180M`）与 Nginx 反向代理模板。
- 完成 `tests/api.test.js` 全流程自动化集成测试验证。
