# Freshness Gate

Knowledge 记录“最后一次确认”，不代表合作条件不会变化。

## Gate A｜合作条件
涉及报价、租金、押金、任务量、结算时：
优先读取最新合同 / 任务单 / 平台后台。
若与知识库不同，实时正式文件优先。

## Gate B｜当前工作
必须确认：
`PROJECT_INDEX.current.active_work_item_id == CURRENT_WORK.work_item_id`

不一致时先修复知识库，不继续扩张决策。

## Gate C｜试采指标
涉及扩设备时，只接受本轮真实审核结果，不使用预估替代实绩。

## Gate D｜公司/市场
涉及公司是否存续、融资、官方政策、行业价格等外部信息时，重新检索最新公开来源。

## Gate E｜付款
每次付款前重新核对：
合同主体、收款主体、金额、用途、退款/结算条件。
