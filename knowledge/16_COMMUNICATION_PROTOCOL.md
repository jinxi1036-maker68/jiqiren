# Communication Protocol｜我们俩怎么配合

## ChatGPT 给 Owner
任何复杂事项优先按：
**结论 → 为什么 → 今天怎么做 → 做到什么算完成 → 风险**

避免：
- 先讲大段行业背景再给结论
- 一次给十几个同等优先级任务
- 用模糊词“尽量、适当、多联系”
- 让 Owner 自己去 GitHub 找执行材料

## Owner 给 ChatGPT
不要求整理，直接发原始信息即可：
- 截图
- 语音转文字
- 联系人和场景
- 对方报价/条件
- 今天发生了什么
- 你自己觉得哪里不对劲

ChatGPT 负责结构化、判断、更新知识库。

## 重要信息回传最小模板
- 对方是谁：
- 说了什么：
- 有没有数字：
- 有没有时间：
- 有没有让我付款/承诺：
- 我现在最担心什么：

## 解释难度规则
当 Owner 表示没听明白时：
- 先换成大白话
- 再给一个现实例子
- 最后只保留“你现在要做的一步”
