# Operating Model & Boundaries

## 当前业务模型
上游平台派发真实场景任务和SOP → 本地团队组织成年人、场景和设备执行 → 数据上传审核 → 按有效时长结算。

## 当前角色
- Owner：商务、重大投入、上游关系、扩张决策
- 现场负责人：培训、排班、设备、质控
- 采集员：按SOP执行
- 场景方：授权真实场所进入和采集
- 上游：任务、设备/平台、审核、结算

## 边界
- 不使用学生、未成年人做采集员。
- 学校等涉及未成年人场景暂不进入。
- 医院、养老、私人住宅、涉密工厂等敏感场景未经专项合规评估不进入。
- 未取得场地方明确授权，不拍摄经营现场。
- 顾客、人脸、车牌、订单、电脑屏幕、商业秘密等必须按项目要求规避/脱敏。
- 不向上游虚构场景、团队规模、历史案例或数据集。

## 规模控制
10台 = 试采验证  
20台 = 稳定运营起点  
30-50台 = 需要成熟现场负责人、质检、场景冗余和现金流后才评估
