## 二、终局第一性原理深清查：跨模块查出的 5 处隐形死角与硬修正

将上述 6 个已锁模块与仓库既有硬件、法务、财税、业务现实交叉核对，暴露出以下 5 处必须在写代码前堵死的隐患：

### 死角 1：现有阿里云服务器内存极紧（1.83GiB）＋ 国内域名 ICP 备案前置周期
- **仓库实测事实**（`2026-11-11_XIAOYOU_LINUX_SERVER_READ_ONLY_AUDIT_RECEIVED.md`）：当前阿里云主机仅 `2 vCPU / 1.83GiB RAM`，且已承载小派派 Pi 飞书服务、`pi-livsyn` 读数、`nginx` 与既有网页，剩余内存紧绷；且原旧域名 10 月曾遇备案拦截。
- **排雷方案**：
  1. **极轻技术栈**：1.0 网站必须采用内存占用 `<100MiB` 的轻量全栈（如 Node.js/Next.js 或 FastAPI + SQLite/轻量 Postgres），**绝不在服务器存大视频文件**（或单独低成本托管/云主机适度升配至 4GiB）；
  2. **备案立即并行**：1.0 内部试行可先走临时测试入口供自己人代理商使用，但**必须同步以「平顶山凌矩信息科技有限责任公司」主体启动正式域名工信部 ICP 备案**，避免 2.0 抖音引流爆发时网站被拦截。

### 死角 2：“熟人特批免押金”可能滑坡成“熟人跳过首件 QA 试采”
- **隐形风险**：1.0 试行期面对“自己人代理商”，极易因人情顺带跳过 1–2 小时首件试采，一旦该熟人转交不靠谱人手猛采 30 小时废片，既伤感情又直接触发上游淘汰连坐。
- **硬修正**：**押金可以按信用分级（内部熟人可后台特批豁免），但「1–2 小时首件试采过审点亮批量绿灯」是系统级死锁，任何人不得跳过**——系统强制实现：`first_piece_status !== 'APPROVED'` 时，禁止提交大批量计费日报。

### 死角 3：1.0 网站上线后“任务大厅空荡或合规路径不清”
- **仓库事实核验**：当前 `PARTNER_LEDGER.json` 中仅灵生有口述已签合同（且旧草案含限制转包条款），第二上游仍在推进。若 1.0 网站做完，后台缺少经核验可合法派发的任务，代理登录见不到真单会流失信任。
- **硬修正**：后台新建任务包时增加**强制合规路径字段**（`WRITTEN_SUBCONTRACT_APPROVED` 已获书面分包许可 / `LINGJU_UNIFIED_TEAM_ACCOUNT` 纳入凌矩统一项目组子账号管控 / `DRAFT_INTERNAL_ONLY` 仅内部筹备），**未勾选合法路径的任务系统禁止向外部代理展示**；1.0 先服务已签妥的真实任务，宁缺毋滥，绝不造假单充门面。

### 死角 4：遗漏了第三位收款方——「IP 场景工厂/门店老板」的场地费发票与税链
- **隐形漏洞**：模块 5 算清了凌矩对甲方开 3% 专票、代理给凌矩开票或扣税点，但若使用平台 IP 场景，凌矩需给外地工厂/门店老板结场地费——如果小店老板同样开不出发票，走公账也会产生无票成本税耗。
- **硬修正**：平台订单财务模型必须拆清**三方独立结算科目**：`代理净得`、`场景方场地费（含凭证/开票/税耗方式字段）`、`凌矩留存毛利`；在设定“使用平台场景的代理净价”时，提前把**场地费＋税耗**一并预扣留足，防止倒贴。

### 死角 5：直接做 B（真 Web 站）极易滑向“重开发泥潭”
- **隐形风险**：若按互联网大厂标准去接短信网关、昂贵电子签章 API、在线支付钱包、大视频转码播放器、实时聊天室，研发周期会拖到 1–2 个月且运维成本暴涨。
- **第一性原理大砍法（1.0 极简真站“五砍五留”）**：
  - **坚决砍掉 5 项重外设**：
    1. 砍掉公开自主注册与短信验证码 → **改为凌矩总控台审核通过后手动发号/重置密码**（0 短信费，且从入口彻底掐死 C 类乱注册！）；
    2. 砍掉第三方付费电子签章接口 → 改为**系统内必勾确认日志（时间/账号/IP）＋ 重要主体协议线下盖章拍照上传归档**；
    3. 砍掉在线钱包与自动打款 → 改为**系统核算三态背靠背账单 ＋ 财务公户转账后上传银行回单凭证**；
    4. 砍掉大视频存储与在线审片 → 改为**仅录入每日原始/上传小时、上传批次号、外链与 QA 驳回文本回执**；
    5. 砍掉站内即时聊天室 → 日常急事直接走微信/飞书，平台只留结构化凭证与状态流转。
  - **只精准开发 5 个真数据库核心模块**：
    1. **认证代理与风控档案库**（账号权限、主体/发票类型、押金/担保状态、历史有效率与违规记录）；
    2. **合规任务分包池**（模态 EGO/夹爪/双目、合规路径标签、自带场景/平台场景两档净价、QA 红线、内部 SOP 正文/附件）；
    3. **全国场景双层池 ＋ 公开极简留资页**（抖音老板 30 秒免登录填表 → 进待初筛队列 → 标 `S2储备` 或 `S1标杆` → 脱敏挂池，锁单后单向解锁真实对接人）；
    4. **两段式派单与首件熔断工作台**（认领申请 → 协议确认 → 审批锁单 → `首件1–2h试采中` → 凌矩验真点亮 `批量绿灯` → 日报填报 → 凌矩回填上游 QA 有效小时与驳回原因）；
    5. **背靠背三方对账台**（严格分上游批次显示 `待甲方QA` → `待甲方回款` → `甲方已回款·待结(N日内)` → `已打款(附回单)`，同步列明代理净额、场景方场地费、税票状态与凌矩毛利）。
