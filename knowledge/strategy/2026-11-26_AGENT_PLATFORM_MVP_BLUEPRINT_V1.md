## 一、V1 核心定位与边界

- **一句话定义**：把凌矩手上的**① 灵生及多上游合规可分包任务**与**② 创始人个人 IP 引流来的全国各地真实工厂/门店场景**装进同一个 S2B 调度工作台，让各地代理在“防跳单、防乱做、账目清”的前提下，就近配对承接并标准化交付。
- **与 `miniapp/`（双端小程序）的关系**：本网站平台服务于 **S2B（凌矩 → 各地代理/合作团队）**；`miniapp/` 服务于 **B2C 微站点（门店商家 → 个人兼职采集员）**。两者底层可共用任务分类与 QA 口径，但在 V1 阶段保持独立，不强行揉成一个庞杂系统。

## 二、三类角色与严格权限隔离（核心是防跳单）

| 角色 | 能看到什么 | 核心操作 | 绝对权限红线 |
|---|---|---|---|
| **1. 凌矩总控台（Admin）** | 上游真实客户名/合同条款、IP 引流来的真实工厂联系人与门牌、全部代理资质与各批次 QA/回款实况 | 上架任务包、初筛脱敏场景、审批代理资质与锁单解锁、回填上游 QA 有效小时、管理对账状态 | 未获上游书面分包许可的订单不得上架为“可分包”；不将未验证回款记为可结算 |
| **2. 区域代理端（Agent）** | **锁单前**：只看脱敏任务包（任务类型/模态/QA要求/代理参考结算价）＋脱敏场景卡（省市/行业/主营工序/可用时段）；**锁单后**：解锁对应单子的真实对接人与完整 SOP | 筛选城市与任务、发起“任务＋场景”配对认领、签署电子保密与不绕单承诺、填报每日采集上传进度、查看 QA 有效率与结算单 | 看不到上游原始客户后台密码、看不到未锁单场景的老板电话门牌、不能跨单/跨上游混用设备与视频 |
| **3. 场景老板留资入口（IP 落地页）** | 仅见极简场景合作介绍与信息登记表单 | 30 秒提交：所在省市、场景类型（工厂/仓库/超市/文具店等）、日常真实干什么活、可开放时段、联系方式 | 看不到任何任务单价、代理列表或平台内部数据；提交后直接进凌矩总控台“待初筛池” |

## 三、V1 最小业务闭环（5 步跑通，不贪大求全）

```
[个人IP抖音流量] ──(30秒留资)──▶ [总控台：待初筛场景池] ──(脱敏上架)──┐
                                                                      ▼
[灵生/多上游商务] ──(合规拆包)──▶ [总控台：上游任务分包池] ──(脱敏上架)──┼──▶ [代理大厅：按城配对认领]
                                                                      ▲         │
                                                                      │   (签不绕单协议 + 总控审批锁单)
                                                                      │         ▼
[总控台：回填QA与账期] ◀──(日报/上传/驳回明细)── [代理工作台：解锁SOP与真场景落地采集]
```

### 第 1 步：双池入库与脱敏封装
- **上游任务包字段**：`任务包编号`、`所属批次/通道（演示脱敏）`、`设备模态（第一视角 EGO / 夹爪 / 双目）`、`适配场景类别`、`代理参考结算单价（按客户QA有效小时）`、`硬性QA红线（如手部出画≤3秒、禁止摆拍等）`、`分包前置授权状态`。
- **IP 场景池字段**：`场景编号（如 SCN-JS-001）`、`省/市/区`、`场景大类（工业轻型装配/仓库/商超文具等）`、`真实日常工序描述`、`可开放时段`、`是否自带操作人员`、`脱敏状态（未解锁 / 已派单锁定）`。

### 第 2 步：代理端“双模式”配对认领
代理进入资源大厅，支持按**所在省市、设备模态、场景类型**筛选，并提供两种现实承接方式：
- **模式 A（有场景的代理领任务）**：代理自己在当地已有合法授权工厂/门店 → 直接认领平台里的“上游任务包”，提交自有场地照片供凌矩初审后开工。
- **模式 B（有执行力缺场地的代理领“任务＋场景包”）**：代理在某市有团队和设备 → 选中该市的**脱敏 IP 场景卡**＋匹配的**上游任务包**，一键发起组合承接申请。

### 第 3 步：电子协议锁单与“交付包”解锁
- 代理点击“申请承接”时，系统强制弹出**《防绕单保密与安全交付确认》**（明确约定：不得绕开凌矩私联平台提供的上游或场景老板、严禁伪造采集或采集无关隐私人员）。
- 经凌矩总控台审核代理资格与配额并点击「批准派单」后，系统才向该代理**单向解锁**该场景的真实店名/联系人，并自动下发完整的**《内部执行 SOP（含避坑清单与复位要求）》**。

### 第 4 步：轻量化进度填报与 QA 质量回传
- 代理每日只需填写 3 个核心数字：`今日开工设备/人次数`、`原始录制小时`、`已上传小时`（附上传批次号或异常说明）。
- 凌矩总控台根据上游实际反馈回填：`审核通过有效小时`、`有效率`、`驳回/返工具体原因`（如“画面遮挡”“动作重复无变化”“场景像临时摆拍”）。
- **铁律**：系统界面清晰拆分**「已上传待审小时」**与**「上游确认有效小时」**，绝不把录制时长直接显示成应发工资或确认收入。

### 第 5 步：账期隔离与透明结算视图
- 为每个派单项目单独展示三态账目：**`待上游QA确认`** → **`上游待回款 / 对账中`** → **`可结算 / 已打款`**。
- 支持按“代理应得（有效小时×分包单价）”“场景方合作费（如适用）”“平台服务费”分别清晰列示，杜绝跨项目混账与无依据垫资。

## 四、最小可演示原型（Clickable Demo）5 个核心界面设计

如果下一步进入网页可点击原型搭建（纯前端 HTML/JS 演示，全部采用显眼标注的虚构样例数据），界面结构收敛为以下 **5 个核心视图**：

1. **顶部演示切换栏（全局导航）**：显著标明`[纯前端演示版 · 虚构数据 · 非真实合同与支付]`，支持一键切换三大视角：**「区域代理端」**、**「凌矩总控台」**、**「IP 场景老板留资页」**，并附“重置演示数据”按钮。
2. **视图一 · 代理端「资源承接大厅」**：
   - 左右/上下双区联动或 Tab 切换：**可承接任务包列表** ＋ **全国脱敏场景池（按省市筛选）**。
   - 卡片直接标出核心吸引力：模态标签、适用场景、QA 关键红线、代理预估单价、匹配状态；未锁单场景明确显示`[已脱敏：派单后解锁详细地址与对接人]`。
3. **视图二 · 代理端「我的交付与结算台」**：
   - 展示已获批的承接单：一键展开对应完整 SOP 与踩坑禁区、提交今日采集与上传日报表单、查看历史批次的模拟 QA 有效率与具体驳回原因、查看按“待QA / 待上游回款 / 已确认可结”拆分的分包账单。
4. **视图三 · 凌矩总控台「中枢调度与风控看板」**：
   - 顶部 4 张核心经营卡：`上架合规任务包数`、`待匹配 IP 场景数`、`活跃代理节点数`、`综合模拟 QA 有效率`。
   - 下方三大操作队列：① **IP 场景线索审核上架队列**（将新提交的老板留资脱敏上架到场景池）；② **代理认领与解锁审批队列**（决定是否解锁真实场景联系方式给代理）；③ **QA 有效小时与账期核销台**（模拟回填某批次有效时长与打回原因，实时联动代理端收益与有效率）。
5. **视图四 · 场景老板「IP 引流极简留资页」**：
   - 模拟金总抖音主页/私信发给外地工厂/门店老板的登记落地页（30 秒填完城市、行业、日常真实作业、可配合时段、称呼与微信），提交后**实时流转进总控台的“待初筛场景池”**，在演示现场即可完整跑通“抖音获客 → 平台脱敏上架 → 代理认领解锁 → 采集交付 → QA 结算”全流程。

## 五、V1 坚决不做的 6 件事（防返工与控成本铁律）

1. **不做真实资金充值、在线支付或自动提现钱包**（前期财务结算必须走公司对公审核与银行回单）。
2. **不直连灵生生产系统 API 或在网页端存放上游账号密码/Cookie**。
3. **不自研视频播放器、大文件视频上传存储服务器或复杂 AI 审片后台**（前期只记录时长、上传批次号、外链或文本回执，避免高额带宽存储成本）。
4. **不开放代理之间私聊或直接在列表暴露老板电话与上游联系人**（防止跳单）。
5. **不把 `miniapp/`（门店+个人采集员）强行并入本网站首版页面**，保持 S2B 代理承接主线极致清晰。
6. **不写死真实敏感价格与真实客户保密数据**，在拿到正式书面分包许可和跑通自营首笔回款前，对外展示一律仅作商业模式演示与内部流程验证。
