# ADR-003｜建立可迁移的区域经营能力，而非追求人头规模

- 决策日期：2026-10-10
- 状态：**OWNER APPROVED / ACTIVE**
- 决策背景：对话中明确选择“平顶山几十家长期合作场景 + 成熟管理体系 + 服务多家客户”，而非单纯拥有50名采集员的队伍。

## 决策
最终目标是建设平顶山区域具身智能真实世界数据运营企业。核心资产优先级：
1. 可合法持续授权使用的真实场景（线索不算授权）；
2. 可复用的招聘、培训、SOP、质检、设备运营和交付体系；
3. 经过真实订单及回款验证的多个上游客户关系；
4. 稳健的单位经济和现金流。

**不以员工总人数、设备台数或某一家平台的单价作为成功的核心指标。**

## 对当前执行的约束
- 近期计划不变：灵生10台试采，景联文/淘丁等并行对接，不提前大规模购置设备。
- 每做完一个阶段，除了核算净收益，还要复盘新增了哪些能被下一家公司继续使用的合法场景和团队能力。
- 不能把上游的项目数据、素材或机密未经授权用于其他客户；“可迁移”仅指自己合法拥有和可复用的资源、经验和流程。
- 规模化决定需要验证：数据通过率、现金占用、场景复用、订单持续性和真实回款。

## 重新评估条件
市场需求、法律要求、设备类型、客户结构或实际回款数据发生重大变化时，Owner 重新审视方向，但不能因为一单报价高就自动推翻长期原则。
